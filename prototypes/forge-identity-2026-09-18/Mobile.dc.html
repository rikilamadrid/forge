Where local intelligence is shaped into tools.

Forge sends a prompt to an Ollama runtime on a machine you already control and hands back a typed result with real execution evidence.

$ npm i forge-local-ai-kit
GitHub npm
ask.mjs 
import { createForge }
  from 'forge-local-ai-kit';

const forge = createForge({
  provider: 'ollama',
  host: process.env.OLLAMA_HOST,
  model: 'qwen3.5:9b',
});

const result = await forge.ask(
  'Name three risks.'
);

console.log(result.output);
